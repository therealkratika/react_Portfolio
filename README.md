## 🚀 Getting Started

### 01 · Clone

```bash
git clone https://github.com/therealkratika/react_Portfolio.git
```

### 02 · Navigate

```bash
cd react_Portfolio/frontend
```

### 03 · Install

```bash
npm install
```

### 04 · Run

```bash
npm run dev
```

Open the local development URL displayed by Vite.
